## 二、RPA 控制台：托管子服务 + 反向代理

### 2.1 为什么这样做

控制台自带一个**纯标准库**的 HTTP 服务（`local_server.py`，`ThreadingHTTPServer`），
自带完整前端（HTML/CSS/JS + ECharts + Monaco，约 19 MB 静态资源）。
与其重写它的 UI，不如**原样托管**：EcomPilot 启动时把它拉起来，通过 `/console/*` 反向代理暴露。

好处：
- 用户只需启动一个进程（`uvicorn backend.main:app`），控制台自动就绪；
- 控制台代码保持零改动（只做了「端口可配置」+「静态资源加 `/console` 前缀」两处最小改造）；
- 前端平台卡片旁多一个入口，点一下新标签页打开完整控制台。

### 2.2 运行时序

```
浏览器 ──GET /console/──▶ FastAPI(/console/{path})
                              │  ensure_started() 首次调用时拉起子进程
                              ▼
                    127.0.0.1:8010  local_server.py
                              │
                    ◀── 原样回传 HTML / CSS / JS / JSON
```

- 子服务监听 `127.0.0.1:8010`（由 `ECOMPILOT_CONSOLE_PORT` 控制）；
- 代理访问子服务时**强制绕过系统 HTTP 代理**（`ProxyHandler({})`），否则会被代理层拦成 502；
- 子进程通过 `lifespan` 在应用启动时拉起、退出时回收。

### 2.3 新增/改动文件

| 文件 | 作用 |
|---|---|
| `backend/api/console.py` | 子服务生命周期管理 + `/console/*` 反向代理 + `/api/console/*` 状态接口 |
| `backend/main.py` | 挂载 `console_router`，`lifespan` 内 `ensure_started()` / `stop_console()` |
| `frontend/react/src/App.jsx` | 新增 `ConsoleEntry` 组件（侧栏卡片），点击调 `/api/console/start` 并新标签页打开 |
| `.env.example` | 新增 `ECOMPILOT_ENABLE_CONSOLE` / `ECOMPILOT_CONSOLE_PORT` |
| `integrations/octopus-rpa-console-dashboard/local_server.py` | `PORT` 由硬编码 8000 改为读 `CONSOLE_PORT` |
| `integrations/octopus-rpa-console-dashboard/web/*` | 前端绝对路径加 `/console` 前缀（7 处资源 + 12 处 API） |

### 2.4 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/console/status` | 子服务状态：`enabled / running / available / port / url` |
| `POST` | `/api/console/start` | 拉起子服务（幂等），返回最新状态 |
| `POST` | `/api/console/stop` | 停止子服务 |
| `GET` | `/console` | 302 → `/console/` |
| `ANY` | `/console/{path}` | 反向代理到子服务（含静态资源与 `/console/api/*`） |

关闭子服务：设 `ECOMPILOT_ENABLE_CONSOLE=0`，此后相关接口返回 503。

### 2.5 本地验证（已实测）

启动 `uvicorn backend.main:app --port 8000` 后：

```
GET /                        → 200
GET /api/console/status      → 200 {"enabled":true,"running":true,...}
GET /console/                → 200 (21661 bytes, text/html)
GET /console/style.css       → 200 (38057 bytes, text/css)
GET /console/app.js          → 200 (165937 bytes, text/javascript)
GET /console/echarts.min.js  → 200 (1029023 bytes)
GET /console/monaco/vs/loader.js → 200 (30051 bytes)
GET /console/fonts/maple-mono.woff2 → 200 (5386156 bytes)
GET /console/api/runs        → 200 (JSON)
GET /console/api/schedule    → 200 (JSON)
GET /api/platforms           → 含 lingxing
```

`index.html` 中所有 `href/src` 均已带 `/console` 前缀，无遗漏。

## 三、脱敏对照表

| 原值类型 | 处理方式 |
|---|---|
| 公司/店铺品牌名（机器人名前缀） | 替换为「甲组 / 乙组」 |
| 内网共享主机名（UNC） | `SX-0x` → `HOST-A-0x`，`BS-0x` → `HOST-B-0x` |
| 写死的公司 ID | → `YOUR_COMPANY_ID`（EcomPilot 侧走环境变量） |
| 写死的盘符路径 | → `./` 或删除 |
| 原作者 GitHub 账号 | → `your-org` |
| `robot_logs.json`（含真实内网主机清单） | 不入库；改提供 `robot_logs.example.json` |
| `console.log`（含内网 IP） | 删除，且已 gitignore |

> 如需在控制台里使用**你自己的**机器人名与日志共享路径，直接编辑
> `integrations/octopus-rpa-console-dashboard/robot_logs.json`（该文件被 gitignore，不会外泄）。

## 四、已知限制

1. 领星接口为**逆向 Web 接口**，非官方 OpenAPI；Cookie 过期需人工重新导出，无自动续期。
2. `X-AK-Version` 硬编码，领星前端升级后可能需要同步更新。
3. RPA 控制台是独立工具，其数据（机器人排期、日志）与 EcomPilot 的分析流水线**尚未打通**；
   当前是「同进程托管 + 统一入口」，后续可考虑把控制台的运行状态做成 EcomPilot 的一个面板。
