# 项目说明书

## 项目定位

EcomPilot AI 是电商老板的 AI 运营参谋。它帮助商家回答：

- 为什么 GMV 高但不赚钱？
- 哪些商品应该主推？
- 哪些商品广告投产不健康？
- 哪些 SKU 有退货或库存风险？
- 今天店铺最大的问题是什么？

## 用户流程

1. 上传商品经营 CSV / Excel。
2. 系统自动清洗字段并计算核心指标。
3. 查看店铺 KPI 和商品分层。
4. 阅读运营诊断和风险提醒。
5. 用 AI 问答追问具体经营问题。
6. 导出日报给老板或团队。

## 验收标准

- 上传示例数据后，前端能展示 GMV、净利润、ROAS、CTR、CVR、退货率。
- 商品表中能看到商品分层、优先级、风险和机会。
- 诊断页能给出核心判断、风险提醒和优化动作。
- 问答页能回答预算、亏损、最大问题和日报类问题。
- API 文档可访问，测试可以通过。

## 简历描述

独立开发 EcomPilot AI 电商运营诊断助手，基于 FastAPI、Pandas、Streamlit 和可选 OpenAI API，实现电商数据上传、核心指标计算、商品分层、AI 运营诊断、问答和日报生成能力。系统可自动分析 GMV、CTR、CVR、ROAS、退货率、净利润、库存风险等关键指标，并生成面向电商老板的可执行优化建议。
