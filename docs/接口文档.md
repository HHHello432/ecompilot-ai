# 接口文档

默认服务地址：`http://127.0.0.1:8000`

## 上传数据

`POST /api/upload`

表单字段：

- `file`：CSV / XLS / XLSX 文件

返回：

```json
{
  "file_id": "file_xxx",
  "message": "上传成功，分析已完成。",
  "warnings": []
}
```

## 载入演示数据

`POST /api/demo`

返回一份内置电商经营数据的分析记录，便于演示和前端联调。

## 下载数据模板

`GET /api/template/download`

返回标准 CSV 模板，用户可填写后重新上传。

## 获取指标分析

`GET /api/analysis/{file_id}`

返回内容：

- `summary`：店铺汇总指标
- `products`：商品级指标、风险标签、机会标签和分层结果
- `warnings`：数据清洗提醒

## 获取运营诊断

`GET /api/diagnosis/{file_id}`

返回：

```json
{
  "file_id": "file_xxx",
  "summary": "当前最大问题是...",
  "alerts": ["风险提醒"],
  "suggestions": ["优化动作"],
  "source": "rules"
}
```

`source` 为 `rules` 表示规则诊断，`llm` 表示已使用大模型增强。

## AI 问答

`POST /api/question/{file_id}`

请求：

```json
{
  "question": "哪些商品最应该加广告预算？"
}
```

返回：

```json
{
  "file_id": "file_xxx",
  "answer": "最适合加广告预算的是..."
}
```

## 生成日报

`GET /api/report/{file_id}`

返回 Markdown 文本，包含老板版结论、运营版拆解和明日必做动作。

## 下载日报

`GET /api/report/{file_id}/download`

返回 Markdown 文件。

## 下载 HTML 报告

`GET /api/report/{file_id}/html`

返回可直接打开或打印的 HTML 运营日报。

## 最近分析历史

`GET /api/history?limit=8`

返回最近分析记录，用于前端展示近次复盘和趋势对比。

```json
{
  "items": [
    {
      "file_id": "demo_latest",
      "saved_at": 1780000000.0,
      "summary": {},
      "diagnosis_summary": "当前最大问题是...",
      "warnings": []
    }
  ]
}
```

## 任务完成状态

`GET /api/tasks/{file_id}`

读取某份分析下今日必做清单的完成状态。

`PUT /api/tasks/{file_id}`

保存今日必做清单完成状态。

请求：

```json
{
  "completed": {
    "daily-review": true,
    "loss:蓝牙耳机青春版": false
  }
}
```

## 平台连接器状态

`GET /api/platforms`

查看抖店、拼多多、淘宝 / 天猫、京东等平台连接器的启用和配置状态。连接器默认关闭，不影响上传文件、演示数据、诊断和日报功能。

返回：

```json
{
  "platforms": [
    {
      "id": "doudian",
      "name": "抖店",
      "enabled": false,
      "configured": false,
      "authorized": false,
      "status": "未启用",
      "capabilities": ["商品", "订单", "售后", "库存", "经营数据"],
      "next_step": "在抖店开放平台创建应用，申请店铺授权后填入 App Key / Secret。",
      "redirect_uri": "http://127.0.0.1:8000/api/platforms/doudian/callback",
      "last_sync_at": null
    }
  ]
}
```

## 发起平台授权

`POST /api/platforms/{platform_id}/auth/start`

连接器启用且密钥完整时，返回平台授权地址。前端会在新窗口打开该地址，引导店铺完成授权。

返回：

```json
{
  "platform_id": "taobao",
  "status": "ready",
  "message": "授权地址已生成，请在平台页面完成店铺授权。",
  "auth_url": "https://oauth.taobao.com/authorize?...",
  "state": "安全随机串",
  "redirect_uri": "http://127.0.0.1:8000/api/platforms/taobao/callback"
}
```

## 平台授权回调

`GET /api/platforms/{platform_id}/callback?code=xxx&state=xxx`

平台授权成功后回调此地址。服务端会校验 `state`，再用 `code` 换取令牌并保存授权状态。令牌只保存在本地 `backend/storage/platforms/`，不会从接口返回给前端。

返回：

```json
{
  "platform_id": "taobao",
  "status": "authorized",
  "message": "店铺授权已保存，后续可从同步入口拉取商品、订单和售后数据。",
  "shop_id": "263685215"
}
```

## 平台同步占位

`POST /api/platforms/{platform_id}/sync`

当前接口用于确认连接器状态和后续接入位置。没有开启平台连接器时会返回 `disabled`，项目仍可正常使用本地上传和演示数据。

返回：

```json
{
  "platform_id": "doudian",
  "status": "disabled",
  "message": "平台连接器未启用，当前项目仍可使用演示数据或上传文件运行。",
  "job_id": "doudian_1780000000"
}
```

返回：

```json
{
  "file_id": "file_xxx",
  "completed": {
    "daily-review": true
  }
}
```
